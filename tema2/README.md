# README

## Objetivo

Este proyecto implementa el algoritmo de la Conjetura de Collatz en Python y JavaScript con el propósito de realizar una comparación de rendimiento mediante pruebas de benchmarking.

## Archivos Incluidos

* `collatz.py`: implementación del algoritmo en Python.
* `collatz.js`: implementación del algoritmo en JavaScript.
* `README.md`: instrucciones para la ejecución y reproducción de las pruebas.

## Requisitos de Software

* Python 3.x
* Node.js v24 o superior

## Ejecución

### Python

```bash
python collatz.py
```

### JavaScript

```bash
node collatz.js
```

## Escenario de Pruebas

La prueba consiste en ejecutar el algoritmo de la Conjetura de Collatz para todos los números enteros comprendidos entre 1 y 100.000.

El tiempo de ejecución es medido utilizando las funciones de temporización incorporadas en cada lenguaje.

## Entorno Utilizado

* Sistema Operativo: Windows 11 Pro 64 bits.
* Procesador: AMD Ryzen 2.1 GHz.
* Memoria RAM: 16 GB.

## Reproducción de Resultados

1. Instalar Python y Node.js.
2. Descargar los archivos del proyecto.
3. Ejecutar los comandos indicados para cada lenguaje.
4. Registrar los tiempos mostrados por consola.
5. Comparar los resultados obtenidos.
