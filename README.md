# LC Project - Programming Exercises

This repository contains a set of Python scripts developed to solve specific computer science problems, focusing on string parsing, formal notation validation, and mathematical sequences.

## 🛠 Project Structure

### 1. Expression Lexer (`Problema1/`)
A simplified lexical analyzer that processes mathematical expressions. It tokenizes the input string into categories: `NUMERO`, `OPERANDO`, `OPERADOR`, `PAREN_IZQ`, and `PAREN_DER`.

### 2. FEN Notation Validator (`Problema2/`)
A validator for **Forsyth-Edwards Notation (FEN)** used in chess. The script analyzes the board layout, active color, castling availability, and move counters to ensure the string conforms to FEN standards.

### 3. Collatz Conjecture Implementation (`Problema3/`)
An implementation of the $3n + 1$ algorithm. The program iterates through a user-defined range of integers and computes the sequence for each value until it converges to 1.

## 🚀 Execution

Ensure you have Python 3.x installed. To run any of the modules:

```bash
python ProblemaX/problemaX.py
```
